# DZ Sign

Application locale de signature de test et de vérification PDF. Le backend est dans `backend/`, l’interface dans `frontend/`.

| العربية | [التثبيت](../docs/ar/installation.md) | [الاستخدام](../docs/ar/usage.md) | [المرجع](../docs/ar/reference.md) |

Les manuels constituent la référence pour les commandes, la configuration, les limites de conservation et les résultats de vérification. Les clés et documents locaux restent sous `.local/dz-sign/` à la racine du projet.

Après installation des dépendances de développement, `python3 scripts/check.py`, lancé depuis la racine, exécute l’ensemble des contrôles. Les constats de revue sont consignés dans le [rapport d’audit](../docs/audit.md).
