# Contribuer à DZ Digital Trust

Les instructions équivalentes sont disponibles en [français](docs/fr/development.md), en [anglais](docs/en/development.md) et en [arabe](docs/ar/development.md).

Une contribution doit répondre à un problème identifié : comportement incorrect, documentation inexacte, difficulté d’utilisation ou besoin du périmètre défini. Décrire le comportement obtenu et joindre les contrôles exécutés. Ne pas ajouter de fonctionnalités factices pour compléter une interface.

Avant de proposer une modification :

1. Installer les dépendances de développement décrites dans le manuel.
2. Exécuter `python3 scripts/check.py`.
3. Mettre à jour les trois manuels si une route, une limite, une commande ou un traitement des données change.
4. Vérifier qu’aucune clé, aucun secret et aucun document personnel n’apparaissent dans les fichiers partagés.

Les messages de commit, si un dépôt est initialisé, sont rédigés en anglais. Les références juridiques doivent préciser le texte, l’article pertinent, la source officielle et la date de consultation. Une source non examinée ne doit pas être présentée comme vérifiée.
