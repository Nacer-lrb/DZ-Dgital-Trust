# DZ Digital Trust handbook

[Français](../fr/README.md) · [العربية](../ar/README.md)

DZ Digital Trust combines a technical study with DZ Sign, a local application for experimenting with PDF signatures. It uses fictional identities and reports verification results separately from legal recognition.

## Scope

PDF import, test signing, signature verification, downloads and JSON export are implemented. Documents expire within fifteen minutes. Electronic seals, approval workflows, user accounts and durable storage are not provided.

This version runs on an individual workstation. It does not establish revocation status, trusted timestamp validity or legal qualification. The application's privacy and terms pages explain its data handling. The interface currently uses French; these handbooks provide equivalent instructions in three languages.
