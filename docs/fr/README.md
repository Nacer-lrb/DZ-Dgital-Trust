# Manuel DZ Digital Trust

[English](../en/README.md) · [العربية](../ar/README.md)

DZ Digital Trust réunit une étude documentaire et DZ Sign, une application locale destinée à expérimenter la signature de PDF. Elle utilise une identité fictive et expose les résultats de vérification sans les confondre avec une reconnaissance juridique.

## Périmètre

L’import, la signature de test, la vérification PDF, les téléchargements et l’export JSON sont disponibles. Les documents expirent après quinze minutes au maximum. Le cachet, les circuits d’approbation, les comptes et le stockage durable ne sont pas fournis.

Cette version fonctionne sur un poste individuel. Elle ne vérifie pas la révocation, l’horodatage de confiance ou une qualification juridique. Les pages de confidentialité et de conditions d’utilisation de l’application décrivent son traitement des données. L’interface utilise actuellement le français ; les manuels fournissent des instructions équivalentes dans les trois langues.
