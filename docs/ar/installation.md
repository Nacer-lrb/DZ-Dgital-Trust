# التثبيت والتشغيل المحلي

[الدليل](README.md) · [Français](../fr/installation.md) · [English](../en/installation.md)

## المتطلبات

نظام Linux أو بيئة POSIX، وPython 3.12، وNode.js 22 أو أحدث، وnpm. يلزم OpenSSL 3 لاختبارات التحقق المستقلة. يحتاج تثبيت الاعتماديات إلى اتصال بالشبكة؛ أما عمليات PDF فلا تجلب موارد خارجية تلقائيًا بعد ذلك.

نفّذ الأوامر التالية من المجلد الرئيسي للمشروع:

<div dir="ltr">

```bash
python3 -m venv .local/dz-sign/venv
.local/dz-sign/venv/bin/python -m pip install -r demo/backend/requirements-dev.txt
.local/dz-sign/venv/bin/python demo/backend/setup_demo.py
```

</div>

لا تعِد إنشاء البيئة إذا كانت موجودة. ينشئ برنامج الإعداد هوية افتراضية داخل `.local/dz-sign/app-identity/`، ويرفض الكتابة فوق هوية موجودة. مدة شهادة التوقيع ثلاثون يومًا. لإنشاء مجموعة جديدة، استخدم `--output` مع مجلد جديد واضبط `DZ_SIGN_IDENTITY_DIR`.

## تشغيل الخدمتين

في الطرفية الأولى، من المجلد الرئيسي:

<div dir="ltr">

```bash
.local/dz-sign/venv/bin/python -m uvicorn app.main:app --app-dir demo/backend --host 127.0.0.1 --port 8000
```

</div>

في الطرفية الثانية:

<div dir="ltr">

```bash
cd demo/frontend
npm ci
npm run dev
```

</div>

افتح `http://127.0.0.1:3000`. حالة الخدمة متاحة في `http://127.0.0.1:8000/api/health`، ووصف الواجهة في `/docs`. أعد تشغيل الخادم بعد تعديل شفرته، وأوقف كل خدمة باستخدام `Ctrl+C`.

## الإعدادات

| المتغير | القيمة الافتراضية |
|---|---|
| `DZ_SIGN_FRONTEND_ORIGIN` | `http://127.0.0.1:3000` |
| `NEXT_PUBLIC_API_ORIGIN` | `http://127.0.0.1:8000` |
| `DZ_SIGN_IDENTITY_DIR` | المجلد `.local/dz-sign/app-identity/` الذي يحدده الخادم |
| `DZ_SIGN_PASSWORD_FILE` | الملف `runtime/signer.secret` داخل مجلد الهوية |

يعدّ المتصفح `localhost` و`127.0.0.1` مصدرين مختلفين. قيم `NEXT_PUBLIC_*` عامة وتُضمَّن عند البناء؛ لذلك يتطلب تغييرها إعادة بناء الواجهة في وضع الإنتاج.

يستخدم التخزين المؤقت مثيل واحد فقط من الخادم. لا تضف عمليات خادم مستقلة ولا تربط الخدمة بالعنوان `0.0.0.0` ضمن هذا النطاق المحلي الذي لا يتضمن مصادقة.

## معالجة الأخطاء

| الحالة | ما يجب التحقق منه |
|---|---|
| تعذر الاتصال | تشغيل الخادم وصحة المنفذ والمصدر وتوافق نسختي الواجهة والخادم |
| التوقيع غير متاح | تجهيز الهوية ووجود المفتاح والسر بصلاحيات `0600` |
| `409` | عملية أخرى قيد التنفيذ أو مثيل آخر يستخدم التخزين |
| `410` | انتهت إتاحة المستند؛ أعد استيراده |
| `413` | تجاوز الأصل أو النسخة الموقعة حد 10 MiB |
| `422` | اقرأ الرسالة: PDF مشفر أو غير مدعوم، أو تأكيد ناقص، أو إعداد هوية غير صحيح |
| `504` | تجاوز مهلة المعالجة؛ تُحذف النتائج الجزئية |

الاستجابة `OPTIONS 200` فحص CORS طبيعي، ولا تعني نجاح طلب `POST` الذي يليه.
