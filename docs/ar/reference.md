# البنية وواجهة البرمجة والأمن

[الدليل](README.md) · [Français](../fr/reference.md) · [English](../en/reference.md)

## المكونات

تعرض Next.js وReact المستندات والتقارير. تضبط FastAPI مصادر طلبات المتصفح والاستيراد ومدة الاحتفاظ. تنفّذ pyHanko عمليات PDF داخل عمليات فرعية. تحفظ ملفات الاعتماديات أرقام الإصدارات المحددة.

يحفظ الخادم البيانات الوصفية في الذاكرة والملفات داخل `.local/dz-sign/uploads/`. لكل مستند معرّف عشوائي، ولا يُستخدم الاسم المرسل مسارًا للتخزين. لا توجد قاعدة بيانات أو حسابات أو استعادة للجلسة بعد إعادة التشغيل.

## عقد HTTP

| الطريقة والمسار | المحتوى أو النتيجة |
|---|---|
| `GET /api/health` | حالة الخدمة وقدراتها الفعلية |
| `GET /api/documents` | المستندات التي لم تنتهِ إتاحتها |
| `POST /api/documents` | نموذج multipart يحتوي ملفًا واحدًا باسم `file` |
| `GET /api/documents/{id}` | البيانات الوصفية ومرجع النسخة الموقعة إن وجدت |
| `GET /api/documents/{id}/download` | الأصل كمرفق للتنزيل |
| `POST /api/documents/{id}/sign` | `{"confirm_test_signature": true}` |
| `POST /api/documents/{id}/verify` | `{"source":"original"}` أو `{"source":"signed"}` |
| `GET /api/results/{id}/download` | النسخة الموقعة كمرفق |
| `DELETE /api/documents/{id}` | حذف الأصل ونسخته |

تأخذ الاستجابة الرمز `200` عندما يُنتج تقرير، حتى إن سجّل `outcome` فشل فحص تشفيري. أخطاء الطلب وتعذر تنفيذ العملية حالتان منفصلتان. يشير `normalized_before_signing` إلى إعادة كتابة بنية ملف هجين قبل توقيعه.

## الحدود المطبقة

| المورد | الحد |
|---|---|
| الملف المستورد أو النسخة المنشورة | 10 MiB |
| غلاف multipart | 10 MiB إضافة إلى 64 KiB، مع فحص الحجم أثناء القراءة |
| المستندات | عشرة؛ أي 200 MiB كحد أقصى للأصول والنسخ الموقعة |
| عمليات PDF النشطة | عملية واحدة |
| المدة | 30 ثانية للاستيراد أو التوقيع أو التحقق |
| عملية PDF الفرعية | 512 MiB من الذاكرة الافتراضية و30 ثانية CPU على POSIX |
| خرج التقرير | 2 MiB |
| الاحتفاظ | خمس عشرة دقيقة كحد أقصى من بدء الاستيراد |

يُفحص انتهاء الإتاحة قبل الوصول. تحتفظ العملية النشطة بملفها حتى توقفها، لكنها لا تنشر نتيجة انتهت إتاحتها. يجري التنظيف كل دقيقة، وعند الإيقاف الطبيعي وبدء التشغيل. تمنع ساعة رتيبة تمديد المهلة بإرجاع ساعة النظام إلى الوراء.

## حدود الثقة

تُشفّر مفاتيح الاختبار بصيغة PKCS#8. صلاحيات المفاتيح والأسرار `0600` وصلاحيات مجلدات المستندات `0700`. يحدد الخادم مسارات المفتاح والسر والجذر؛ ولا تسمح أي نقطة نهاية للعميل باختيارها. لا تُرسل الأسرار إلى المتصفح.

لا تجلب العمليات الفرعية موارد شبكية تلقائيًا. بروتوكول JSON بينها وبين العملية الرئيسية محدود الحجم وتُفحص بنيته. يُرفض الخرج غير المقروء بدل اعتباره نجاحًا.

فحصا المصدر وHost ليسا مصادقة. هذا الإصدار مخصص لمستخدم محلي واحد. القيود التطبيقية ليست عزلًا كاملًا على مستوى النظام، ويمكن لعملية تعمل بالحساب نفسه الوصول إلى التخزين. الحذف لا يضمن محوًا جنائيًا للوسيط.

## الواجهة

السجل ولوحة المعالجة منفصلان عن التقرير. الإرشادات والخصوصية وشروط الاستخدام صفحات فعلية. حالات التحميل والفراغ والخطأ وانتهاء الإتاحة واضحة. لا تعرض الواجهة مستندات أو إحصاءات أو تجارب مصطنعة لملء المساحة.
