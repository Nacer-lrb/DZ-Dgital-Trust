# دليل DZ Digital Trust

[Français](../fr/README.md) · [English](../en/README.md)

يجمع المشروع بين دراسة تقنية وتطبيق محلي اسمه DZ Sign لتجربة توقيع ملفات PDF والتحقق منها. يستخدم التطبيق هوية افتراضية، ويفصل نتائج التحقق التقني عن الاعتراف القانوني بالتوقيع.

## نطاق الإصدار

يدعم التطبيق استيراد PDF، وتوقيع نسخة تجريبية، والتحقق من التوقيعات، وتنزيل الملفات وتصدير تقرير JSON. تنتهي إتاحة المستندات خلال خمس عشرة دقيقة كحد أقصى. لا يتضمن الإصدار إنشاء الأختام الإلكترونية أو مسارات الموافقة أو حسابات المستخدمين أو التخزين الدائم.

هذا الإصدار مخصص لمحطة عمل فردية. ولا يثبت حالة إلغاء الشهادة أو صحة ختم زمني موثوق أو التأهيل القانوني للتوقيع. توضح صفحتا الخصوصية وشروط الاستخدام داخل التطبيق طريقة معالجة البيانات. واجهة التطبيق بالفرنسية حاليًا، وتوفر هذه الأدلة تعليمات متكافئة باللغات الثلاث.
