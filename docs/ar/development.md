# التطوير والمساهمة

[الدليل](README.md) · [Français](../fr/development.md) · [English](../en/development.md)

## تنظيم الشفرة

يحتوي `demo/backend/app/` مسارات HTTP والتخزين المؤقت وبروتوكول العمليات الفرعية والإعدادات. يتضمن `examples/` العمليات التشفيرية والتجارب. تفصل الواجهة عقود JSON عن نقل HTTP وعرض السجل والتقرير.

إصدارات الاعتماديات محددة في ملفاتها. لا تعدّل الحزم المثبتة أو ملفات إطار العمل المولدة لتجاوز خطأ. تبقى المفاتيح والمستندات المحلية داخل `.local/dz-sign/`، وهو مستبعد في `.gitignore` إذا أُنشئ مستودع لاحقًا.

## التحقق من المشروع

بعد تثبيت اعتماديات التطوير:

<div dir="ltr">

```bash
python3 scripts/check.py
```

</div>

يشغّل الأمر اختبارات Python والتحليل الساكن وفحص التنسيق، ثم فحوص الواجهة وبناءها. يلزم OpenSSL للفحوص التشفيرية المستقلة؛ وعند غيابه تصرّح بعض الاختبارات بأنها لم تُنفَّذ.

لتنسيق الشفرة:

<div dir="ltr">

```bash
.local/dz-sign/venv/bin/ruff format demo/backend examples scripts
cd demo/frontend
npm run format
```

</div>

تشمل الاختبارات المفاتيح المشفرة والبصمات المعروفة وسلاسل الشهادات وملفات PDF المعدلة أو الهجينة وانتهاء الإتاحة ومصادر HTTP وتنظيف العمليات. أضف اختبارًا لعيب يمكن إعادة إنتاجه أو لتغيير في العقد، لا لإعادة كتابة تفاصيل التنفيذ داخل التأكيدات.
