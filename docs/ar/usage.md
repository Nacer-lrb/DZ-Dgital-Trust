# المستندات وتقارير التحقق

[الدليل](README.md) · [Français](../fr/usage.md) · [English](../en/usage.md)

## تجربة التطبيق

أنشئ مستندًا افتراضيًا باسم ملف غير موجود مسبقًا:

<div dir="ltr">

```bash
mkdir -p .local/dz-sign/documents
.local/dz-sign/venv/bin/python examples/pdf-signing/create_demo_pdf.py .local/dz-sign/documents/attestation.pdf
```

</div>

اختر الملف ثم اضغط «Importer le PDF». يتيح اختيار اسمه في السجل عرض بياناته والعمليات المتاحة. السجل مشترك بين اتصالات مثيل الخادم المحلي، ولا يرتبط بحساب مستخدم أو علامة تبويب واحدة.

للتوقيع، اختر «Signer une copie de test» وأكّد استخدام الهوية الافتراضية. يبقى الأصل محفوظًا، وتعيد الطلبات المتكررة النسخة الموقعة نفسها. يمكن التحقق من ملف موقّع مسبقًا، لكن هذا المسار لا يضيف إليه توقيعًا آخر.

تُعاد كتابة بنية ملف PDF الهجين غير الموقّع داخل النسخة قبل توقيعها، مع بقاء القراءة الصارمة مفعّلة. توضح الواجهة هذه المعالجة. لا تدّعي النسخة الحفاظ على البايتات أو جميع المعرّفات الداخلية كما كانت.

## قراءة التقرير

اختر الأصل أو النسخة الموقعة ثم ابدأ التحقق. يفصل التقرير سلامة البيانات، وصحة التوقيع التشفيري، والثقة في الشهادة، وفترة صلاحيتها، ونطاق البيانات التي يغطيها التوقيع.

| النتيجة | معناها |
|---|---|
| `checks_passed_with_limits` | نجحت الفحوص المحلية ضمن الحدود المعلنة |
| `checks_failed` | فشل فحص واحد على الأقل؛ اقرأ النتائج المفصلة |
| `needs_review` | تحتاج التعديلات أو الصلاحيات إلى مراجعة |
| `no_signature` | لم يُكتشف توقيع تشفيري |
| `indeterminate` | لا يتيح التحليل الوصول إلى نتيجة حاسمة |

لا يثبت هذا الإصدار حالة الإلغاء أو موثوقية الختم الزمني أو الصلاحية التاريخية أو التأهيل القانوني. صورة الإمضاء لا تحل محل توقيع تشفيري.

## الاحتفاظ بالنتائج أو حذفها

نزّل الأصل أو النسخة الموقعة أو تقرير JSON قبل انتهاء الإتاحة. يشترك الملفان في مهلة أقصاها خمس عشرة دقيقة تبدأ مع الاستيراد. حذف الأصل يزيل نسخته الموقعة من الخدمة أيضًا. تظل الملفات التي سبق تنزيلها في المكان الذي اختاره المتصفح.

## أمثلة سطر الأوامر

<div dir="ltr">

```bash
python3 examples/python/sha256_file.py README.md
.local/dz-sign/venv/bin/python examples/certificate-generation/generate.py
.local/dz-sign/venv/bin/python examples/pdf-signing/sign_pdf.py input.pdf output.pdf --pki .local/dz-sign/pki
.local/dz-sign/venv/bin/python examples/pdf-signing/verify_pdf.py output.pdf --trust-root .local/dz-sign/pki/trust/root.cert.pem --json
```

</div>

البنية التحتية لشهادات الأمثلة منفصلة عن هوية التطبيق. يطلب المولّد التفاعلي عبارات مروره الخاصة. لا يحتاج التحقق إلى مفتاح خاص، ويجب أن تطابق شهادة الجذر تلك المختارة للتجربة.

</div>
